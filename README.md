# МТУСИ · Мастерская проектов

Полный локальный проект FastAPI + React + TypeScript. В комплекте 29 экранов первого МК, заметки ведущего, ручное голосование, таймер, карта экранов и сохранение занятия. Интерфейс и содержание на русском. Бело-фиолетовая палитра; официальный логотип не используется.

## Быстрый запуск на Windows

1. Распакуйте весь архив в отдельную папку. Нужен Python 3.11+ с Python Launcher (`py`).
2. Запустите `setup_windows.bat` один раз. Для установки Python-зависимостей нужен интернет.
3. Запустите `start_windows.bat`.
4. Откройте **http://127.0.0.1:8000** в Chrome или Edge.
5. Нажмите «Начать занятие». F11 включает полноэкранный режим браузера.

**Собранный frontend уже включён. Node.js для проведения МК не нужен.** После установки Python-зависимостей внешняя сеть не требуется: шрифты системные, внешних CDN, ИИ API и аккаунтов нет.

Если Windows не знает команду `py`, установите Python с python.org с Launcher или замените `py -3` на путь к вашему Python. Если порт 8000 занят, измените его в start-скрипте и адресе браузера. Окно сервера оставляйте открытым; Ctrl+C останавливает сервер.

Linux/macOS: `bash setup.sh`, затем `bash start.sh`; тот же адрес браузера.

## Два способа проведения

**Дублирование экрана:** откройте занятие и нажмите F11. Видны слайды и компактная панель управления, заметки не показываются. Кнопка «Пульт» открывает заметки в отдельной вкладке; не показывайте её на дублируемом экране.

**Рекомендуемый вариант с заметками:** Windows Win+P → «Расширить». В занятии откройте «Пульт». В пульте нажмите «Открыть экран зала», перенесите это окно на проектор и нажмите F11. Пульт оставьте на ноутбуке. В окне зала нет кнопок управления и заметок. Окна синхронизируются через локальный сервер примерно раз в 0,7 секунды.

Только F11 скрывает интерфейс браузера; клавиша F включает Fullscreen API страницы. Разрешение проектора желательно 1280×720 и выше, масштаб браузера 100%. Перед занятием проверьте читаемость с последнего ряда. Если выбран очень крупный системный масштаб, уменьшите масштаб браузера.

## Управление

- → / PageDown / пробел: сначала показать вывод, затем следующий экран.
- ← / PageUp: скрыть вывод или вернуться на предыдущий экран.
- R: показать/скрыть вывод; G: карта экранов; F: полноэкранный режим страницы.
- 1–8: выбрать соответствующий вариант. Повторное нажатие снимает выбор.
- На финальном упражнении можно выбрать три действия; маленькие номера показывают их порядок.
- Таймер обсуждения запускается из пульта. Доступны 60, 90, 120 и 600 секунд. Пауза и смена экрана останавливают таймер.
- На доске задач щёлкните карточку, чтобы переместить её в следующую колонку. Изменение сразу видно в окне зала.
- Кнопки в пульте дублируют управление. Горячие клавиши не перехватываются при фокусе на интерактивном элементе; щёлкните по пустой области.

На главной странице есть последние занятия. Они хранятся в `data/workshops.sqlite3` и переживают перезапуск сервера. Экспорт занятия сохраняет JSON с решениями и состоянием для анализа; обратный импорт экспорта занятия пока не реализован. Сброс очищает только выбранное занятие после подтверждения.

## Новые мастер-классы

На главной странице «Загрузить сценарий» принимает JSON до 2 МБ. Формат описан в `docs/SCENARIOS.md`. Скачайте текущий сценарий кнопкой JSON или используйте `docs/scenario-example.json`. Включённый пример - техническая демонстрация, **не готовый МК 2**.

Новый сценарий должен иметь уникальный `id`. Повторный импорт того же id отклоняется, чтобы не затереть материалы. Для новой версии меняйте id, например `toolkit-v2`. Занятие хранит собственную копию сценария, поэтому последующие импорты его не меняют. Файлы из `scenarios/` добавляются при старте только при отсутствии их id в базе; для обновления используйте новый id.

Проигрыватель уже поддерживает переходы по выбору, игровые метрики и возврат с восстановлением состояния. Условные метрики не рассчитываются для МК 1. QR, мобильные голоса и роли участников пока не включены; архитектурные точки расширения описаны в `docs/ARCHITECTURE.md`.

## Разработка

Python 3.11+; для пересборки интерфейса Node.js 22.12+ (или 24 LTS) и npm.

Backend из корня:
```
.venv/Scripts/python -m uvicorn app.main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```
На macOS/Linux путь `.venv/bin/python`.

Frontend во втором терминале:
```
cd frontend
npm ci
npm run dev
```
Vite проксирует `/api` к порту 8000. После изменений `npm run build`; перезапустите backend для запуска одной службы с обновлённой сборкой.

Тесты (из корня, Linux/macOS):
```
.venv/bin/pip install -r backend/requirements-dev.txt
PYTHONPATH=backend .venv/bin/python -m pytest backend/tests -q
```
В PowerShell сначала `$env:PYTHONPATH="backend"`, затем `.venv\Scripts\python -m pytest backend/tests -q`.

Swagger API: http://127.0.0.1:8000/docs. JSON Schema сценария: http://127.0.0.1:8000/api/schema.

## Эксплуатация

Сервис предназначен для вашего ноутбука, по умолчанию слушает только localhost. Авторизации, публичных комнат и защиты роли ведущего для подключения школьников ещё нет. Не выставляйте текущий API в общую сеть как готовый сервис голосования. Для следующего этапа добавим роли и отдельный API участников.

Резервная копия: остановите сервер и скопируйте `data/workshops.sqlite3`. В архиве поставки база и тестовые занятия отсутствуют.
