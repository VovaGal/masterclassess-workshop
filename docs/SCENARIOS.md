# Формат сценария v1

Полный пример: `scenario-example.json`. Рабочий МК: `../scenarios/toolkit.json`. Машиночитаемая схема доступна в `/api/schema` и `scenario.schema.json`.

Верхний уровень: `schema_version: 1`, уникальный `id` (латиница в нижнем регистре, цифры, дефисы, подчёркивания), `title`, `subtitle`, `description`, `start` (id первого экрана), `metrics` (словарь исходных числовых ресурсов), `slides`.

Экран: `id`, `title`, `section`, `layout`, `minutes`, `body` (до 8 текстовых пунктов), `code` (необязательный текст кода), `reveal` (выводы), `notes`, `choices`, `selection_limit`, `columns`, `next`.

Макеты: title, cards, choice, code, board, flow, break, summary. Flow и summary используют текстовые последовательности с общей типографикой. Board принимает `columns`: заголовок колонки → список карточек. Начальное состояние задано сценарием. Ведущий нажимает карточку для перемещения в следующую колонку; из последней колонки она возвращается в первую. Изменения сохраняются в занятии и видны на экране зала.

Notes: `talk` и `activity` - массивы тезисов; `important` и `short` - строки. Они доступны в пульте, а не на проекторе. Для короткого экрана не добавляйте всю лекцию в body.

Вариант: `id`, `label`, необязательный `feedback`, `next`, `effects`. Поля effects изменяют только заранее объявленные metrics. Один выбор по умолчанию; `selection_limit: 3` разрешает три действия в порядке нажатия, но исключает индивидуальные next.

Порядок перехода: next выбранного варианта → next экрана → следующий элемент массива. Последний экран остаётся на месте. Без выбранного варианта используется общий переход. «Далее» сначала раскрывает reveal, если он задан; повторное нажатие переходит дальше. Через карту можно пропустить любой экран.

У каждого экрана должен быть уникальный id; все переходы ссылаются на существующие id. Дополнительные неизвестные поля отклоняются. До 200 экранов, файл до 2 МБ. Импорт с уже существующим id сценария не заменяет его: создайте новую версию с новым id.

Для крупного экрана: 3-5 коротких пунктов или 3 варианта. Не более 6 коротких вариантов в упражнении. Все тексты выводятся как текст, вставка HTML и выполнение кода из сценария не поддерживаются. Поле code - демонстрация, не Python-интерпретатор.
